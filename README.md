# 木木的单词本

> 
> 前端单词记忆网页应用，本地浏览器存储单词，适合单词背诵练习，作为前端个人作品集项目。

## ✨ 项目介绍

这是一个纯前端实现的单词本单页网站，**所有数据保存在浏览器 LocalStorage，无需后端服务器**。
可以添加英文 - 中文单词，划分学习阶段，支持复习、总览、单词练习功能，界面为固定尺寸的卡片式页面，导航栏可切换不同功能页面。
适合用来记忆英语单词。

## 📌 功能清单

1. **多页面导航**：首页、新词添加页、总复习页、单词练习页
2. **单词状态流转**
   - 新添加单词默认归入【新词】栏，首页新词栏最多展示 7 个
   - 新词点击√ → 移动到首页【复习】栏，复习栏最多展示 7 个
   - 复习栏单词点击√ → 标记为已完成，不再在首页展示，保留在总复习
   - 任意单词可点击 × 删除
3. **添加新词**
   - 输入英文、中文释义，查重：英文 + 中文组合重复时提示【添加失败】，输入框高亮绿色边框
   - 添加成功自动跳转首页；删除按钮一键清空输入框
4. **总复习页面**：展示**全部保存的单词**（所有状态，不受首页 7 条限制）
5. **单词练习**
   - 两种模式：顺序抽取、随机抽取，每次抽取 10 个单词
   - 点击卡片切换显示英文 / 中文释义
6. **本地持久存储**
   - 单词保存在浏览器 LocalStorage，关闭网页再次打开，单词不会丢失
   - 首次打开网页无数据时，自动预置 10 条示例单词方便预览演示
7. **辅助弹窗**
   - 悬浮【联系】弹窗：展示开发者联系方式
   - 悬浮【使用方法】弹窗：项目使用说明，页面首次加载自动弹出

## 🛠️ 技术栈

- HTML：页面结构搭建
- CSS：页面样式、布局、点击按压动效
- JavaScript：页面切换、单词增删、状态管理、本地存储、练习逻辑

> 
> 纯前端，无后端，无数据库，直接打开 html 文件即可运行

## 📖 使用方法

1. 下载项目，在本地文件夹打开 `index.html` 文件（直接用浏览器打开）
2. 顶部导航栏切换页面：
   - **首页**：查看新词、待复习单词（每栏最多 7 条），可标记完成 / 删除单词
   - **新词**：录入英文 + 中文，添加新单词；重复内容会提示添加失败
   - **总复习**：查看所有存入的单词
   - **练习**：选择顺序 / 随机，抽取 10 个单词，点击卡片切换中英文
3. 右下角悬浮按钮：查看联系信息 / 查看使用说明

> 
> ⚠️ 注意事项
> 
> 
> 1. 单词数据保存在当前浏览器，清除浏览器缓存会清空单词
> 2. 更换浏览器 / 无痕模式打开，读取不到原有单词
> 3. 仅本地网页，没有上传到服务器，数据仅保存在本机浏览器
